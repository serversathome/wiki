# What is Secret Santa?
A festive Secret Santa party organizer with Christmas theme and snow animations.
# :logos:docker-icon: 1 · Deploy Secret Santa

::block-steps
1. Navigate to your `stacks` directory
1. Run the commands
    ```bash
    git clone https://github.com/richard1912/SecretSanta
    mv SecretSanta secretsanta
    cd secretsanta
    ```
1. Refresh your Dockge UI
1. Change `BASE_URL=` to your server IP:Port
1. Deploy
::
